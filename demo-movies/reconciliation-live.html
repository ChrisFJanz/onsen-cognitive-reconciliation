Reconciling the IETF L3SM service model (RFC 8299) to a TM Forum representation, with no full mapping agreed in advance. Agent Y works the YANG side, Agent T the TMF side, over a thin shared reference. Most of the run sits at one placement, both systems inert under a single over-arching cognition; the closing drift event and the service-to-network case reach the both-cognitive end and are marked where they do. Each panel is marked for where moving toward both-cognitive buys a real, measured advantage, and where it buys nothing.

About this demonstrator — what you're looking at, and what is real

Neither system here is cognitive. A single over-arching cognition reconciles two inert models from their static artifacts. That is the realistic placement today, and the demonstrator stays honest to it: the two agents are the two roles of one reasoning loop over static models, not two live systems interrogating each other. The spectrum strip above shows where the run sits, and every stage is tagged for whether a more cognitive placement would add anything.

Everything scored is a real harness run. The authority-withheld locate scatter, the 209-characteristic annotated mapping, the empty residual, the instance round-trip, and the drift detection and re-reconciliation are the published harness's actual outputs, replayed from recorded transcripts. The conversational lines are a readable rendering of those runs, not invented. Anyone can reproduce them with their own API licence.

With no annotations, each agent must decide which nodes are the customer-facing services before any mapping. Across ten independent trials the agents produced the same set of service roots only three times (root agreement 0.30). The scatter is not noise; it sorts into three kinds the methodology already names.
Fills in at the locate stage.
A thin reference — not YANG, not TMF — pinning identity only. Each side binds its concepts here; entries light up as they bind. Binding rests on the description, never a bare name, which is what screens a false cognate.
The structural gap. The YANG side nests containers and lists; the TMF side is a flat collection of Features linked by composedOf. A real ontological difference, not a naming one, and what the translators transform.

The one case the standard leaves open. YANG empty is absent from the draft's type table. Without an anchor the agents waver between boolean and string across trials; the reference, or a one-line specification, pins it so it does not re-diverge. This is the single place a more cognitive placement could close the case by itself.
